# Лабораторная работа 1. Консольный набор утилит

Python-пакет с CLI, содержащий калькулятор выражений и конвертер физических величин.

## Структура проекта
```bash
lab_01/
pyproject.toml
README.md
src/
toolkit/
init.py
main.py
calculator.py
converter.py
errors.py
tests/
test_calculator.py
test_convert.py
test_cli.py
```

## Описание модулей

`__main__.py` это точка входа CLI. Разбирает аргументы командной строки через `argparse`, вызывает нужную утилиту и печатает результат в `stdout`. Все пользовательские ошибки выводятся в `stderr`, код возврата при этом равен 2. Успешный запуск завершается кодом 0.

`calculator.py` это вычислительное ядро калькулятора. Состоит из четырех этапов: токенизация конечным автоматом, валидация с выделением унарных знаков, перевод в обратную польскую нотацию алгоритмом Дейкстры и вычисление через стек. `eval`, `exec` и сторонние парсеры не используются. Функции ядра не вызывают `input` и `print`, поэтому его можно тестировать напрямую, без запуска CLI.

`converter.py` это конвертер величин. Поддерживает три группы: длина (`mm`, `cm`, `m`, `km`), масса (`g`, `kg`) и температура (`c`, `f`, `k`). Регистр единиц не учитывается. Перевод между разными группами запрещен, температура ниже абсолютного нуля также запрещена. Результат всегда возвращается как `float`.

`errors.py` содержит иерархию исключений. Все пользовательские ошибки наследуются от общего класса `ToolkitError`, что позволяет в CLI ловить их одним `except`.

## Установка

Из корня проекта:

```bash
pip install -e .
```
После этого пакет toolkit доступен в текущем окружении, и команда python -m toolkit работает из любой директории.

Запуск
Калькулятор принимает выражение одной строкой:

bash
python -m toolkit calc "2+3*4"
Конвертер принимает значение и две единицы измерения:

bash
python -m toolkit convert 1000 --from mm --to m
Справка по командам:

bash
python -m toolkit --help
Калькулятор
Поддерживаются четыре бинарные операции: +, -, *, /. Умножение и деление имеют приоритет над сложением и вычитанием. Перед числом может стоять унарный + или -, в том числе после другого оператора, например 1+-2. Пробелы между токенами игнорируются.

Числа могут быть целыми и вещественными. Точка в числе обязательно должна быть окружена цифрами. Запись 2.5 корректна, записи 2. и 2..5 считаются ошибками.

Если выражение синтаксически некорректно или содержит деление на ноль, ядро выбрасывает исключение, CLI печатает сообщение в stderr и завершается с кодом 2.

Конвертер
Поддерживаются следующие единицы:

длина: mm, cm, m, km

масса: g, kg

температура: c, f, k

Регистр не важен, MM и mm обозначают одно и то же. Конвертация между разными группами запрещена, например kg в m даст ошибку. Для температур проверяется абсолютный ноль: значение ниже -273.15 c или его эквивалент в других шкалах дает ошибку AbsoluteZero.

Тесты
bash
python -m pytest
Тесты разбиты на три файла. test_calculator.py покрывает вычислительное ядро калькулятора, test_convert.py покрывает ядро конвертера, test_cli.py запускает пакет через subprocess и проверяет коды возврата и содержимое stdout и stderr. Ядро тестируется напрямую, без обращения к CLI.

Коды возврата
0 при успешном выполнении команды

2 при пользовательской ошибке, сообщение выведено в stderr

Ограничения
Калькулятор не использует eval, exec, ast.literal_eval и сторонние библиотеки для разбора выражений. Скобки в текущей версии не поддерживаются. Дополнительные операции вроде // и % тоже не реализованы.
